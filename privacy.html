BDD Publisher

Privacy policy

Last updated: 24 October 2026

BDD Publisher ("the tool") is an internal publishing tool operated by the owner of the YouTube channel Billion Dollar Disasters. It is used only by the channel owner, with his own Google account. It has no other users.

What data the tool accesses

  • Through Google OAuth 2.0, with the channel owner's consent: permission to upload and manage videos, thumbnails, captions and playlists on his own YouTube channel, and to read that channel's YouTube Analytics and Reporting data.
  • It does not access any other user's account, channel or personal data.

How the data is used

Only to publish the owner's videos and to produce aggregate performance summaries (views, watch time, retention, impressions, click-through rate) for the owner's own channel, which are used to improve future videos.

Storage and sharing

  • The OAuth refresh token is stored as an encrypted secret in a private GitHub repository controlled by the owner.
  • Aggregate analytics summaries for the owner's channel are stored in the same private repository.
  • No data is sold, shared with third parties, or used for advertising.

Google API Services

The tool uses YouTube API Services and complies with the Google API Services User Data Policy, including the Limited Use requirements. By using it, the account owner agrees to the YouTube Terms of Service; Google's privacy practices are described in the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time at Google account permissions. Stored analytics summaries are deleted on request or within 30 days of access being revoked.
